# dds · 打地鼠

> 休闲打地鼠小游戏 · 纯前端 PWA · 离线可玩 · 无任何依赖
>
> 在线体验：https://unplage.github.io/dds/

---

## 一、原版诊断（对标商业打地鼠）

对标 *PopCap Whack-a-Mole*、*他她猫/摩尔庄园式打地鼠* 等商业小游戏，原版存在以下问题：

| 维度 | 原版现状 | 问题 |
| --- | --- | --- |
| 节奏 | `setInterval` 定时器，难度全程恒定 | 无难度曲线，越到后面越单调；定时器漂移 |
| 同屏 | `activeMoles` 虽为数组，实际**最多只有 1 只**地鼠 | 商业版核心的"多目标并发"缺失，操作密度过低 |
| 目标 | 只有普通地鼠 | 缺少风险/收益决策（黄金地鼠、炸弹） |
| 反馈 | 纯 CSS 椭圆 + 两只眼睛 | 形象简陋，无粒子、无震屏、无命中特效 |
| 判定 | 空击 −5、逃脱 −3，惩罚过重 | 新手挫败感强，连击极易中断 |
| 数据 | 只有全局最高分 | 无分难度纪录、无命中率、无评级 |
| 交互 | `touchstart` + `click` 双绑定 | 存在重复触发风险；无键盘可达性 |
| 视觉 | 单文件 CSS 硬编码配色、CDN 引入 Font Awesome | 离线图标失效、样式不可维护 |
| PWA | 图标是 `data:` URI 的 SVG；`start_url` 写死 `/dds/` | Chrome 不接受 SVG data URI 做安装图标；换目录即失效 |
| SW | 预缓存未包含真实资源 | 离线时 CSS/JS/图标全部失效 |

## 二、本次重写：玩法升级

* **多地鼠并发 + 动态难度曲线**
  改用 `requestAnimationFrame` + 时间驱动，同屏地鼠数、出场间隔、停留时长随本局进度线性收紧
  （标准档：间隔 1150→560ms、停留 1150→760ms、同屏 2→4 只）。

* **五种地鼠（决策点）**

  | 类型 | 分值 | 停留 | 特性 |
  | --- | --- | --- | --- |
  | 普通地鼠 | 10 | 1.0× | 基础分 |
  | 瞌睡地鼠 | 5 | 1.45× | 出现久、分值低 |
  | 愤怒地鼠 | 20 | 0.62× | 窜得快 |
  | 黄金地鼠 | 60 | 0.72× | 限时出现，分值翻数倍 |
  | 炸弹 | −40 | 1.2× | **千万别碰**，震屏 + 扣分 |

* **连击倍率系统**：2.2s 内连续命中叠加倍率（×1 → ×8），带可视化倒计时条与倍率横幅。

* **道具系统**：连击每满 5 次自动触发，循环生效
  黄金锤（得分翻倍 6s）· 冰冻（地鼠冻结 4s）· 星光（地鼠全部变金 5s）· 慢动作（时间减速 5s）· 护盾（抵消一次炸弹）。

* **结算与评级**：命中率 / 最高连击 / 黄金地鼠 / 踩到炸弹 / 存活时长 + S–D 评级 + 新纪录标记；
  分数按难度分别存档（localStorage）。

* **体验细节**：3-2-1 倒计时、暂停/继续、切后台自动暂停、严格模式（空击/逃脱扣分）可选、
  四档难度 + 无尽模式、键盘（空格暂停 / Enter 开始 / Tab 聚焦洞口）可达、`prefers-reduced-motion` 降级。

## 三、画面升级

* **Canvas 动态场景**：天空渐变 + 日月 + 漂浮云层 + 双层远山 + 草地渐变/草丛/小花 + 花粉粒子，
  三套主题（草原 / 黄昏 / 夜晚）。
* **SVG 地鼠**：矢量绘制，随类型切换配色与表情（眯眼、怒眉、冒烟引线、Zzz），
  洞口为"泥土坑 + 前景土沿"三层结构，地鼠真正从洞里探头。
* **打击感**：泥点迸溅、金色火花、爆炸粒子、彩带、扩散圆环、屏幕震动、命中定格（hit-stop）、
  浮动分数、连击横幅、红光晕冲击。
* **桌面端木槌光标**：跟随鼠标、命中时挥击动画。
* **UI 全面重制**：毛玻璃 HUD、环形倒计时、玻璃拟态面板、3D 按压按钮、纯内联 SVG 图标
  （不依赖 emoji 字体，任何设备渲染一致）。

## 四、PWA 升级

* `manifest.json`：`id`/`start_url`/`scope` 全部相对化（任意子目录可用）、
  192/512 PNG + maskable 图标、桌面/移动快捷方式、商店截图、`display_override`。
* `sw.js`：预缓存清单补全（HTML/CSS/JS/manifest/全部图标），缓存版本化，旧缓存自动清理，
  导航请求网络优先 + 缓存兜底，静态资源缓存优先，离线兜底页。
* 新增 `apple-touch-icon` / `theme-color` / `appinstalled` 安装提示 / 新版本更新提示。

## 五、图标设计

* 主题：**「探头地鼠 + 悬停木槌」**——一眼说明玩法，暖棕地鼠 + 草绿底 + 金色星点。
* 文件：`icons/icon.svg`（主源）、`icons/icon-maskable.svg`（安全区版）、
  `icons/favicon.svg`（16px 简化版）；渲染产物 `icon-192/512`、`icon-maskable-192/512`、
  `apple-touch-icon.png`、`favicon.ico`。
* 重新生成：`python3 tools/make_icons.py`（需 `cairosvg`、`pillow`）。

## 六、目录结构

```
dds/
├── index.html          # 页面骨架（首页/暂停/结算/设置 四个面板）
├── styles.css          # 全部样式（含三套主题变量）
├── app.js              # 游戏引擎（循环、生成、判定、音效、粒子、存档）
├── manifest.json       # PWA 清单
├── sw.js               # Service Worker（预缓存 + 离线）
├── favicon.ico
├── icons/              # 图标与商店截图
└── tools/make_icons.py # 图标渲染脚本
```

## 七、本地运行

```bash
python3 -m http.server 8080     # 任意静态服务器均可
# 打开 http://localhost:8080/
```

部署到 GitHub Pages：把仓库推到 `gh-pages` 分支或开启 Pages 即可，路径自适应。

## 八、隐私

全部数据（最高分、设置、统计）仅保存在浏览器 `localStorage`，不上传任何服务器。
