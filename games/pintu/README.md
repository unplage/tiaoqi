# 🧩 巨幕拼图工坊 (pintu)

真实锯齿拼图 · 三模式 · 闯关 / 每日挑战 / 成就 · 全屏自适应 · 离线可玩

在线试玩：https://unplage.github.io/pintu/

---

## 🎮 玩法

上传图片或选用内置演示图，选择模式与难度，还原图像即可获胜。
碎片是带**凸榫 / 凹槽**的真实拼图块，相邻边缘形状互补，只有正确拼合时曲线才会严丝合缝。

### 三种游戏模式

| 模式 | 操作 | 胜利条件 |
|---|---|---|
| 🧩 交换拼图 | 点击两块交换，或把碎片拖到另一块上 | 全部碎片归位 |
| 🎯 滑动拼图 | 点击空位同行/列的碎片，或朝空位方向滑动 | 空位回到右下角，图像还原 |
| 🔄 旋转拼图 | 点击旋转 90°，左右滑动旋转 ∓90° | 全部碎片转正 |

> 滑动模式打乱时经过奇偶置换校验，**保证必然可解**；交换模式保证开局没有一块在正确位置。

### 计分与评级

- **连击**：一次操作让多块同时归位会叠加连击倍率（最高 ×8），单次得分 `100 × 新归位块数 × 连击`
- **时间奖励**：在标准用时内完成可获得额外时间分，完美通关再 +500
- **星级**：按得分相对关卡目标分评定 1–3 星；过关即解锁下一关
- **金币**：通关、每日挑战、成就都会奖励金币，用于超额使用道具

## ✨ 功能特性

- **真实拼图块**：贝塞尔凸榫/凹槽几何，逐块离屏预渲染，多边形命中测试，拖动即拿起
- **吸附锁定**：归位的碎片自动锁定并显示绿色光晕（可在设置中关闭）
- **道具系统**：提示 / 洗牌 / 显影 / 撤销 / 还原；每局各送 1 次免费，之后消耗金币
- **新手引导**：首次进入逐步演示三种模式的核心操作
- **关卡模式**：3 章 9 关，难度递进，记录每关星级与最好成绩
- **每日挑战**：每天按日期生成固定题目与模式，连胜累计
- **成就系统**：16 枚徽章（首胜、零提示、极速、连击大师、坚持每日……）
- **自动续玩**：随时离开，下次打开可从上次进度继续（12 小时内）
- **非正方形网格**：行列各 2–8 自由设置
- **最佳战绩**：按「模式 × 尺寸」记录最佳用时、步数、星级、对局与胜场
- **内置图库**：8 张 canvas 程序生成图案（落日 / 几何 / 森林 / 波光 / 樱花 / 极光 / 都市 / 沙漠），离线可用
- **高清渲染**：按 devicePixelRatio 缩放，大屏清晰；移动端触摸友好
- **音效 + 音乐**：WebAudio 差异化音效与程序化背景音乐，均可开关
- **庆祝效果**：通关彩纸粒子 + 星级弹层
- **PWA 离线**：Service Worker 预缓存，断网可玩；支持安装到桌面

## 📂 项目结构

```
pintu/
├── index.html          # 单文件应用（HTML + CSS + JS 全部内联）
├── manifest.json       # PWA 清单
├── sw.js               # Service Worker 离线缓存
├── icons/              # 应用图标（PNG / SVG / ICO）
│   ├── icon-192.png    # 普通图标 any
│   ├── icon-512.png    # 普通图标 any
│   ├── icon-maskable-192.png  # 自适应图标 maskable（内容在安全区内）
│   ├── icon-maskable-512.png
│   ├── icon-180.png    # iOS apple-touch-icon（不透明）
│   ├── favicon-16/32.png, favicon.ico
│   └── icon.svg        # 矢量源文件
└── tools/
    └── make_icons.py   # 图标生成脚本（仅开发时需要，运行时零依赖）
```

无构建工具、无第三方依赖（图标与演示图均程序生成），直接打开或本地起服即可：

```bash
python3 -m http.server 8080
# 浏览器访问 http://localhost:8080
```

修改图标后重新生成：

```bash
python3 tools/make_icons.py   # 需要 cairosvg / Pillow
```

## 🛠 技术要点

- **单文件 PWA**：全部逻辑内联于 `index.html`，无模块系统、无运行时依赖
- **拼图几何**：每块的四条边由 `(起始点, 控制点1, 控制点2, 终点)` 的贝塞尔曲线描述，凸榫高低取边长比例；相邻块共享同一条边（符号取反），因此拼合后轮廓连续
- **渲染管线**：每块按「正确摆放」预渲染到离屏 canvas，主画布再按当前状态旋转/位移贴回，配 `Path2D` 裁剪与阴影
- **命中测试**：每块维护独立多边形（含凸榫），`pointer` 坐标做点在多边形内判断，命中失败时回退到所在格子
- **图标可复现**：`tools/make_icons.py` 用纯 SVG 参数化绘制，输出 any / maskable / apple-touch / favicon 全套 PNG
- **缓存按项目隔离**：`sw.js` 依据自身路径推导项目标识（如 `/pintu/` → `pintu`），缓存名为 `pwa-cache-<项目>--v<版本>`；激活时只删除**本项目**的旧版本缓存，绝不触碰同域其它 PWA 的缓存；请求也只拦截本项目作用域，避免跨项目缓存污染
- **滑动可解性**：Fisher-Yates 打乱 + 奇偶置换校验（宽为奇数看逆序数奇偶，宽为偶数还需加上空位行数），洗牌道具同样校验
- **每日题目**：日期字符串哈希作种子驱动 PRNG，同一天所有玩家题目一致
- **动画**：requestAnimationFrame 插值实现碎片交换/滑动/旋转过渡与消除光环
- **持久化**：`localStorage`（`pintu_records_v1` / `_achievements_v1` / `_settings_v1` / `_progress_v1` / `_session_v1` / `_tutorial_v1`）
- **演示图**：canvas 2D 程序绘制，`toDataURL` 转图片，无需网络
